`run-trace.pb.base64` is a base64-encoded OTLP `ExportTraceServiceRequest` serialized with the Go OTLP protobuf types and `google.golang.org/protobuf/proto.Marshal`. It contains one synthetic span, an intentionally private prompt attribute, and fixed-length placeholder UUIDs for its run and attempt. The journey replaces those UUIDs with the IDs created by its gateway workflow before posting the fixture.
